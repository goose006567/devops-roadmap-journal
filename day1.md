# Day 1 Notes

## CI/CD
Continuous Integration and Continuous Delivery - automating the process of testing code changes and deploying them to production so you can release updates frequently and reliably without manual steps.

## IaC
Infrastructure as Code - managing servers and cloud resources through code files instead of clicking around in web consoles, so your infrastructure is versioned and reproducible.

## Containers
Containers package an application with all its dependencies and configuration into a standardized unit that runs the same way on any machine, solving the "works on my laptop" problem.

## Observability
The ability to understand what's happening inside your systems by collecting logs, metrics, and traces, so you can debug issues and know when things break before users complain.
